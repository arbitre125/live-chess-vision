# ♟️ Live Chess Vision — نظام الشطرنج الحي بالكاميرا

<div dir="rtl">

نظام مفتوح المصدر ينقل نقلات الشطرنج من الرقع الحقيقية على الطاولات إلى الإنترنت **لحظياً** — كاميرا واحدة فوق كل رقعة تكشف النقلات بالرؤية الحاسوبية وتدفعها إلى موقع النادي عبر GitHub API.

**مصمم لـ**: نادي سبورتينغ أريانة للشطرنج — أريانة، تونس 🇹🇳
**يعمل على**: Raspberry Pi 4 + Pi Camera (متوافق مع Pi 3B+)
**التكلفة**: ≈ 800 دينار تونسي لكل رقعة (انظر [قائمة المكونات](hardware/BOM.md))

</div>

## 🎯 كيف يعمل؟

```
┌──────────────┐   إطارات    ┌──────────────────┐   نقلات    ┌─────────────┐   GitHub API   ┌─────────────┐
│ Pi Camera    │ ──────────> │ خدمة الرؤية       │ ─────────> │ صفحة الأدمن  │ ────────────> │ موقع النادي  │
│ فوق الرقعة   │  2 fps      │ OpenCV + مقارنة   │  من/to     │ Next.js     │  boards.json  │ Vue (Home)  │
└──────────────┘             │ مربعات 64        │            │ chess.js    │               │ ألعاب حية   │
                             └──────────────────┘            └─────────────┘               └─────────────┘
```

1. **التقاط**: كل كاميرا تلتقط إطارين في الثانية
2. **استخلاص**: homography من زوايا الرقعة المعايرة يقسّم الصورة إلى 64 مربعاً
3. **الكشف**: مقارنة بصمة كل مربع (سطوع + تباين) مع الإطار المرجعي
4. **الاستنتاج**: مربع هجر + مربع تلقى = نقلة؛ يُصحّحها chess.js وتُرفض غير الشرعية
5. **النشر**: صفحة الأدمن تدفع `boards.json` إلى فرع موقع النادي كل 30 ثانية

## 📁 هيكل المستودع

| المجلد | المحتوى |
|--------|---------|
| `admin-app/` | صفحة الأدمن (Next.js 16) — إعداد كل كاميرا + معايرة + عرض مباشر + مزامنة |
| `vision-service/` | خدمة بايثون للراسبيري — التقاط + كشف النقلات (OpenCV) |
| `firmware/arduino/` | وحدة اختيارية: أردوينو + LEDs + أزرار + بازر لكل طاولة |
| `hardware/` | قائمة المكونات بالأسعار التونسية + التوصيلات والتركيب |
| `docs/` | دليل الربط مع موقع النادي + الوثيقة الشاملة (Word) |
| `scripts/` | تثبيت تلقائي كامل على الراسبيري |

## 🚀 التثبيت على الراسبيري (5 دقائق)

```bash
# على Raspberry Pi OS Bookworm حديث
git clone https://github.com/arbitre125/live-chess-vision.git
cd live-chess-vision
bash scripts/setup_pi.sh          # يثبت كل شيء ويعمل الخدمتين تلقائياً
```

ثم افتح من أي جهاز في نفس الشبكة:

```
http://raspberrypi.local:3000
```

## 📋 خطوات التشغيل الأولى

1. **أضف كاميرا** من تبويب «الكاميرات» — اسم + نوع (picamera2/USB/IP)
2. **اعرضها** — إما من أداة `calibrate.py` التفاعلية (انقر الزوايا الأربع) أو أدخل الإحداثيات يدوياً
3. **احفظ المعايرة** — يظهر مت preview للشبكة 8×8 للتأكد
4. **أدخل اللاعبين** في تبويب «الرقع والألعاب» واضغط «بدء لعبة»
5. **اضبط المزامنة** — التوكن + المستودع + الفرع (تُدفع تلقائياً بعدها)
6. **نقلات حقيقية** — سيكتشفها النظام وتراها في موقع النادي خلال ~30 ثانية

## 🔧 استكشاف الأخطاء السريع

| المشكلة | الحل |
|---------|------|
| الكاميرا لا تُفتح | تحقق من `vcgencmd get_camera` — يجب `detected=1`؛ وتأكد من كابل CSI |
| نقلات خاطئة متكررة | ارفع حساسية الكشف في معايرة الكاميرا + حسّن الإضاءة |
| لا تُكتشف نقلات | أنزل الحساسية + تأكد أن الرقعة ثابتة والقطع لا تهتز |
| المعايرة تنحرف | الكاميرا تحركت — أعد المعايرة واشدّ الحامل |
| المزامنة تفشل | تحقق من التوكن (صلاحية Contents فقط) والفرع |
