# ♟️ Live Chess Vision v2 — الشطرنج الحي بعقد ESP32 WiFi

<div dir="rtl">

نظام مفتوح المصدر ينقل نقلات الشطرنج من الرقع الحقيقية إلى الإنترنت **لحظياً** —
**عقد كاميرا ESP32 رخيصة تعمل بالبطارية عبر WiFi** تبث الفيديو إلى خادم مركزي واحد
للبطولة كلها، ويكشف النقلات بنماذج **LeYOLO** من مشروع
[CameraChessWeb](https://github.com/Pbatch/CameraChessWeb) (منفذة إلى بايثون في هذا المستودع)،
ثم تدفع النقلات إلى موقع النادي عبر GitHub API.

**مصمم لـ**: نادي سبورتينغ أريانة للشطرنج — أريانة، تونس 🇹🇳
**يعمل على**: أي حاسوب (حاسوب النادي يكفي) أو Raspberry Pi 4/5
**التكلفة**: ≈ **130 دينار للعقدة الأولى** و**~46 دينار للرقعة الواحدة** في بطولة كاملة
(حتى 4 رقع لكل عقدة — انظر [قائمة المكونات v2](hardware/BOM_v2.md))

| | v1 القديمة | **v2 الحالية** |
|---|---|---|
| العتاد لكل رقعة | راسبيري ~800 د.ت | عقدة ESP32 ~35 د.ت |
| الكشف | مقارنة بقع بكسل | **نموذج LeYOLO مدرّب** (قطع + آزوايا) |
| الاكتشاف | معايرة يدوية لكل رقعة | **اكتشاف تلقائي لكل الرقع في الإطار** |
| الطاقة | كهرباء دائماً | **بطارية 20+ ساعة** أو كابل |
| الترقيات | يدوية (تخمين) | يكتشف فئة القطعة المرقّاة من النموذج |

## 🎯 كيف يعمل؟

```
┌─────────────┐  MJPEG/WiFi  ┌────────────────────┐  نقلات  ┌────────────┐  GitHub  ┌─────────────┐
│ عقد ESP32    │ ───────────> │ الخادم المركزي      │ ───────> │ صفحة الأدمن │ ───────> │ موقع النادي  │
│ 1..6 عقد     │   فيديو حي   │ خادم الرؤية Python  │ SAN/UCI  │ Next.js     │ boards.  │ Vue (Home)  │
│ ببطارية/كابل │              │ ONNX: قطع+آزوايا    │          │ chess.js    │ json     │ ألعاب حية   │
└─────────────┘              │ 1 كاميرا ← 4 رقع    │          │ + مزامنة    │          └─────────────┘
                             └────────────────────┘          └────────────┘
```

1. **البث**: عقدة ESP32 + OV2640 تبث MJPEG عبر WiFi (SXGA 1280×1024، تعمل ببطارية).
2. **الكشف**: خادم الرؤية يشغّل منفذ CameraChessWeb (أكواد المشروع الأصلي منفذة إلى
   بايثون في `vision-service/ccw/`): نموذج القطع يكشف كل قطعة وفئتها،
   ونموذج آزوايا × يثبّت مواقع الرقع.
3. **تعدد الرقع**: لكل رقعة homography من زواياها — عقدة واحدة تغطي 3–4 رقع
   بالدوران بينها. خوارزمية «أزواج النقلات» تلتقط نقلتين وقعتا أثناء فحص رقع أخرى.
4. **الشرعية**: كل نقلة تتحقق في chess.js (صفحة الأدمن) وتُرفض غير الشرعية تلقائياً.
5. **النشر**: صفحة الأدمن تدفع `boards.json` إلى فرع موقع النادي
   `feature/live-chess-games-sporting-ariana` كل 30 ثانية.

## 📁 هيكل المستودع

| المجلد | المحتوى |
|--------|---------|
| `esp32-firmware/` | فيرموير عقدة ESP32-CAM / WROOM-32U: بث MJPEG + بوابة إعداد + توفير طاقة + قياس بطارية + [القطع والبرمجة](esp32-firmware/PARTS-and-FLASHING.md) |
| `vision-service/` | خادم الرؤية (Python/FastAPI) — **منفذ CameraChessWeb** (`ccw/`) + عميل بث + موزّع رقع متعددة + اكتشاف تلقائي |
| `admin-app/` | صفحة الأدمن (Next.js 16، عربية RTL) — عقد الكاميرات + معاينة حية + اكتشاف تلقائي + رقع وألعاب + مزامنة GitHub |
| `hardware/` | [قائمة مكونات v2 بالدينار](hardware/BOM_v2.md) + [الطاقة والبطارية 8+ ساعات](hardware/power-battery.md) + [تموضع الكاميرات لتغطية 3–4 رقع](hardware/multi-board-placement.md) |
| `docs/print/` | مولّد قالب علامات × للطباعة على A4 (لزقها على الرقع) |
| `docs/` | دليل الربط مع موقع النادي + الوثيقة الشاملة (Word) |
| `firmware/arduino/` | (اختياري v1) وحدة LEDs + أزرار + بازر للطاولات |
| `scripts/` | تثبيت تلقائي للخادم المركزي |

## 🚀 التثبيت على الخادم المركزي (5 دقائق)

```bash
# على حاسوب Linux / macOS / Raspberry Pi (Windows: استخدم WSL أو يدوياً)
git clone https://github.com/arbitre125/live-chess-vision.git
cd live-chess-vision
bash scripts/setup_server.sh      # يثبت بايثون + النماذج + الخدمتين تلقائياً
```

ثم افتح من أي جهاز في نفس شبكة النادي:

| الخدمة | الرابط |
|--------|--------|
| صفحة الأدمن | `http://<خادم>:3000` |
| حالة خادم الرؤية | `http://<خادم>:8000/health` |
| بث عقدة ESP32 مباشرة | `http://chesscam-1.local/stream` |

## 🧭 أول تشغيل (مرة واحدة لكل عقدة)

1. **الرقع**: اطبع قوالب علامات × (`docs/print/`) وضعها على الرقع.
2. **العقدة**: برمجها (5 دقائق — [الدليل](esp32-firmware/PARTS-and-FLASHING.md))،
   شغّلها ببنك طاقة أو حزمة 18650، ضبط WiFi من شبكة `ChessCam-XXXX`.
3. **الموضع**: ضعها بارتفاع 2–2.5م وزاوية 55–65° موجهة لكتلة طاولات
   ([التفاصيل](hardware/multi-board-placement.md)).
4. **الأدمن**: الكاميرات ← إضافة عقدة ← رابط البث ← **اكتشاف تلقائي** ← التقط وضعية الرقع ← عش!
5. **النشر**: المزامنة ← أدخل توكن GitHub ← تفعيل الدفع التلقائي → موقع النادي يعرض مباشرة.
