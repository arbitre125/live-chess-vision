# صفحة الأدمن — Live Chess Vision Admin

تطبيق Next.js 16 يعمل على الراسبيري ويوفر واجهة عربية RTL كاملة لإدارة نظام النقلات الحية.

## الميزات

| التبويب | الوظائف |
|---------|---------|
| **لوحة التحكم** | إحصاءات حية: كاميرات متصلة، رقع مباشرة، نقلات 24 ساعة، حالة المزامنة |
| **الكاميرات** | إضافة/تعديل/حذف كاميرا لكل رقعة + معايرة زوايا الرقعة الأربع بمعاينة بصرية + حساسية الكشف |
| **الرقع والألعاب** | لوح شطرنج حي، أسماء اللاعبين، سجل النقلات، بدء/إنهاء/أرشفة، تصدير PGN |
| **المزامنة** | إعدادات GitHub (توكن/مستودع/فرع)، دفع يدوي أو تلقائي كل 30 ثانية، معاينة JSON |

## التشغيل على الراسبيري

```bash
# من جذر المستودع
echo 'DATABASE_URL="file:./prisma/dev.db"' > admin-app/.env
cd admin-app
bun install          # أو npm install
bun run db:push
bun run dev          # التطوير — http://raspberrypi.local:3000
# أو للإنتاج:
bun run build && bun run start
```

## واجهات API

| المسار | الطرق | الوظيفة |
|--------|-------|---------|
| `/api/status` | GET | حالة النظام + مزامنة تلقائية |
| `/api/cameras` | GET/POST | إدارة الكاميرات |
| `/api/cameras/[id]` | PATCH/DELETE | تعديل/حذف كاميرا |
| `/api/cameras/[id]/calibrate` | GET/POST | حفظ/قراءة المعايرة |
| `/api/boards` | GET/POST | الرقع |
| `/api/boards/[id]` | GET/PATCH/DELETE | تفاصيل رقعة + بدء/إنهاء/تصفير |
| `/api/boards/[id]/move` | POST | استقبال نقلة (من خدمة الرؤية أو يدوياً) |
| `/api/games` | GET | أرشيف الألعاب |
| `/api/settings` | GET/PUT | إعدادات النظام وGitHub |
| `/api/sync` | GET/POST | معاينة/تنفيذ الدفع للمستودع |
| `/api/simulate` | POST | نقلة اختبار (بدون كاميرات) |

## ملاحظات

- خدمة الرؤية (`vision-service/`) ترسل النقلات إلى `/api/boards/[id]/move` تلقائياً.
- زر «نقلة اختبار» وزر «محاكاة تلقائية» لأغراض العرض والتجربة فقط.
- التوكن يُخزن في قاعدة بيانات محلية على الراسبيري ولا يُرسل لأي جهة غير GitHub API.
