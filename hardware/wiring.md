# التوصيلات والتركيب المادي 🔌

## 1. تركيب الكاميرا فوق الرقعة (الأهم في المشروع)

### المبدأ
الكاميرا تنظر إلى الرقعة **من الأعلى عمودياً** (زاوية 90°) لضمان:
- رؤية كل المربعات الـ 64 دون حجب من اللاعبين
- معايرة ثابتة لا تتغير

### الطرق العملية (اختر ما يناسب قاعتك)

**الطريقة A — ذراع معلّق فوق الطاولة (الأسهل):**
```
        ┌─────────┐
        │ الكاميرا │   ← Pi Camera موجهة لأسفل
        └────┬────┘
             │ كابل CSI بطول 50سم
             │
        [ ذراع حامل ]      ← حامل ميكروفون/هاتف مثبت على حافة الطاولة
             │
   ══════════╪══════════
   أ ║  ▓▒░ ░▒▓  ║ ب      ← الرقعة على الطاولة
   ════════════════════
```
- الارتفاع: **80 – 120 سم** فوق سطح الرقعة
- الكاميرا Module 3 Wide تغطي رقعة قياسية من 100سم بسهولة

**الطريقة B — إطار خشبي/معدني فوق الطاولات (للبطولات):**
- أنبوب PVС أو خشب يمتد فوق صف الطاولات
- ثبّت الكاميرات بلاستيك ZIP ties بمسافات متساوية
- الأنسب لقاعة بها طاولات متجاورة

### ضبط الكاميرا
1. ثبّت الكاميرا بحيث تملأ الرقعة معظم الإطار (اترك هامش 10-15%)
2. اجعل حواف الرقعة موازية لحواف الصورة قدر الإمكان (يقلل أخطاء المعايرة)
3. شدّ الكاميرا جيداً — أي اهتزاز بعد المعايرة يتطلب إعادة معايرة

## 2. توصيلات الراسبيري

```
 Pi Camera Module 3          Raspberry Pi 4
 ┌────────────┐            ┌──────────────────┐
 │  CSI موصل  │══ كابل 15pin ══>│ منفذ CAMERA (CSI) │
 └────────────┘            │                  │
                           │  microSD (النظام) │
        ⚡ USB-C 5V/3A ═══>│  الطاقة           │
                           │                  │
        Ethernet/WiFi ════>│  الشبكة → النادي  │
                           └──────────────────┘
```

> ⚠️ **قبل التوصيل**: افصل الطاقة عن الراسبيري عند تركيب/فك كابل الكاميرا —
> الكابل الحساس يُتلف بالتوصيل الساخن. الفتحة المعدنية في الكابل تواجه منفذ USB.

## 3. توصيلات الأردوينو (الوحدة الاختيارية)

```
 Arduino Uno                      الراسبيري USB-A
 ┌──────────────┐                 ┌─────────────┐
 │ D2 ← زر أخضر │→ GND            │  USB (بيانات) │
 │ D3 ← زر أحمر │→ GND   USB══════>
 │ D5 → LED أخضر│→ 220Ω → GND     └─────────────┘
 │ D6 → LED أصفر│→ 220Ω → GND
 │ D7 → LED أحمر│→ 220Ω → GND
 │ D8 → Buzzer  │→ 220Ω → سماعة → GND
 └──────────────┘
```

| المرسل (Pi → Arduino) | المعنى | رد الأردوينو |
|----------------------|--------|--------------|
| `EVT:MOVE` | نقلة جديدة | نغمة قصيرة |
| `EVT:CHECK` | كش! | نغمتان |
| `EVT:MATE\|1-0` | نهاية المباراة | لحن نصر |
| `EVT:STATE:LIVE` | لعبة مباشرة | LED أخضر ثابت |
| `EVT:STATE:WAIT_SYNC` | انتظار مزامنة | LED أصفر وامض |
| `EVT:STATE:ERROR` | خطأ كاميرا | LED أحمر وامض |

من طرف الأردوينو: `CMD:START_GAME` و `CMD:FINISH_GAME` عبر Serial —
يمكن للراسبيري قراءتها بسكربت صغير وتحويلها لنداءات API.

## 4. الإضاءة — شرط نجاح الكشف البصري

✅ **افعل:**
- إضاءة موحدة فوق كل الرقع (شريط LED أبيض 4000-6500K)
- ضوء مائل يقلل ظلال القطع

❌ **تجنب:**
- ضوء الشمس المباشر المتغير أثناء اليوم (يخدع مقارنة الصور)
- لمبات فلورسنت القديمة (وميض غير مرئي يفسد الإطارات)
- ظلال اللاعبين على الرقعة (ارفع الإضاءة بعيداً عن مسار ظل الجالسين)

## 5. قائمة تحقق ما قبل التشغيل ✅

- [ ] الرقعة ثابتة على الطاولة (لا تتحرك بين الجولات)
- [ ] الكاميرا مثبتة بإحكام ولا تهتز
- [ ] الصورة تُظهر الرقعة كاملة بهامش واضح
- [ ] الإضاءة موحدة وثابتة
- [ ] الراسبيري متصلة بالشبكة (كابل Ethernet أفضل من WiFi)
- [ ] المعايرة حُفظت من صفحة الأدمن ونجح "معاينة الاختبار"
- [ ] اخترت نقلة تجريبية وظهرت في سجل النقلات
