# الطاقة والبطارية — عقدة ESP32 تعمل 8+ ساعات 🔋

المطلب: عقدة تعمل بالبطارية **8 ساعات على الأقل** (يوم بطولة كامل)،
وإمكانية تشغيلها **على الكهرباء مباشرة عبر كابل** أثناء التطوير أو عند توفر مآخذ.

## أولاً: استهلاك العقدة

حالات تشغيل ESP32-CAM أثناء بث MJPEG (SXGA 1280×1024):

| الحالة | التيار عند 5V |
|--------|--------------:|
| بث مستمر (خادم يستهلك البث) | 140–260 mA |
| بث خفيف (idle FPS منخفض) | 90–140 mA |
| ذروة لحظية (إرسال إطار) | حتى 320 mA |

> ⚠️ ذروات التيار قصيرة — أي مصدر طاقة يجب أن يعطي 500mA على الأقل.

نستخدم 150mA كمتوسط حذر للبطاريات: **0.75 واط** لكل ساعة تشغيل.

## الخيار أ: بنك طاقة USB (الأسهل — موصى به للبدء) ⭐

```
[بنك طاقة 10000mAh] --USB-A إلى micro-USB--> [ESP32-CAM 5V/GND]
```

| البند | القيمة |
|-------|--------|
| طاقة البنك | 10000mAh × 3.7V = 37Wh |
| طاقة فعالة (فقد المحول) ×85% | ~31Wh |
| الاستهلاك | 0.75W |
| **الاستقلالية** | **~40 ساعة نظرية / 25–30 ساعة فعلية** ✅✅ |

- أي بنك طاقة يفي — بشرط أن يكون به خاصية الإخراج المستمر (معظمها).
- أثناء الشحن من الكهرباء يمكن أن يعمل العقدة **ويُشحن معاً**.
- التكلفة: 45–70 د.ت. صفر لحام.

## الخيار ب: حزمة 18650 (الأرخص على المدى الطويل)

### المكوّنات (لكل عقدة)

| # | القطعة | ملاحظات |
|---|--------|---------|
| 1 | 2× بطارية 18650 بسعة 3000–3400mAh | موصولتان **على التوازي** (+ مع + و − مع −) |
| 2 | حامل 2×18650 | بحامل مزدوج جاهز |
| 3 | وحدة TP4056 مع حماية (مع ESP8266 أو النسخة USB-C) | الشحن 1A + حماية تفريغ زائد |
| 4 | مرفع جهد MT3608 (Boost 5V) | يرفع 3.0–4.2V إلى 5.0V |
| 5 | مفتاح صغير + SS34 ديود (حماية اختيارية) | قطع/وصل + منع رجوع التيار |
| 6 | أسلاك توصيل + شريط عازل/أنبوب تقليص | |

### مخطط التوصيل

```
 [+BAT]──┬──[حامل 18650 #1 +]──┬──[TP4056 B+]
         └──[حامل 18650 #2 +]──┘
 [−BAT]──┬──[حامل #1 −]────────┬──[TP4056 B−]
         └──[حامل #2 −]────────┘

 [TP4056 OUT+] ──[مفتاح]──[MT3608 IN+]
 [TP4056 OUT−] ────────────[MT3608 IN−]

 [MT3608 OUT+ (اضبط 5.0V قبل التوصيل!)] ──[ESP32-CAM 5V]
 [MT3608 OUT−] ─────────────────────────[ESP32-CAM GND]
```

### الشحن والتشغيل على الكهرباء مباشرة
- مدخل TP4056 (micro-USB أو USB-C حسب النسخة): اربطه بكابل إلى الشاحن —
  **يمكن اللعب والشحن في نفس الوقت**.
- أو أثناء وجود مأخذ قريب: اشحن بانك USB وأعد توصيله — بديل مرن.
- اضبط MT3608 على 5.0V (قِس بمقياس) **قبل** توصيل الكاميرا.

### الحساب
| البند | القيمة |
|-------|--------|
| السعة | 2 × 3400mAh = 6800mAh عند 3.7V ≈ 25Wh |
| طاقة فعالة (مرفع 85% + حماية) | ~21Wh |
| الاستهلاك | 0.75W |
| **الاستقلالية** | **~28 ساعة نظرية / 20–24 ساعة فعلية** ✅✅ |

حتى بعقدة واحدة 18650 (12–14 ساعة) تتجاوز مطلب الـ8 ساعات بمرجعيات —
نوصي باثنتين للتقليل من عمق التفريغ (إطالة عمر البطاريات).

## الخيار ج: كهرباء مباشرة (تثبيت دائم في القاعة)

```
[مأخذ 220V] → [محول 5V/2A USB] → كابل ≤ 5 متر → [ESP32-CAM 5V]
```
- محول الهاتف القديم يفي (5V/1A على الأقل).
- كابل أطول من 5م؟ استخدم كابل USB بجودة جيدة (قلب نحاس) أو ضع عقدة أقرب.

## نصائح إطالة عمر البطارية في الفيرموير (مفعّلة تلقائياً)

1. **إطفاء LED الفلاش** — لا يُشغل إلا بطلب.
2. **خفض FPS عند الخمول**: بعد 5 دقائق دون مستهلك بث، تنخفض العقدة من 12 إلى 2 FPS
   (تستهلك ~40% أقل). يتصل خادم الرؤية بالبث فقط أثناء البطولة.
3. **إيقاف نوم المودم مع بقية الإعدادات رشيقة** (`WiFi.setSleep(false)` للبث المتواصل فقط).
4. قياس البطارية مدمج: مقاومتا 100kΩ على التوالي من + البطارية إلى GPIO34،
   ويظهر الجهد والنسبة في `http://chesscam-1.local/status` — وتُعرض في صفحة الأدمن.

```
+BAT ──[100kΩ]──┬──[100kΩ]── GND
                │
            GPIO34
```
